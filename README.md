# Student Names

Flashcards for learning students' names from their faces. Each class gets a tab.

- Guess the name in your head, then mark **Correct** (→ or swipe right) or **Wrong** (← or swipe left).
- **Space** or tap the photo reveals the name; **T** shows the tip; **Z** undoes.
- Wrong answers go to the ❌ Learning bin and come back in random order until everyone is in ✅ Learned.

To add a class, put resized photos in `photos/<class-id>/` and add an entry to `classes.js`.
